# web/data/

Processed terrain window and rover traverse used by the app. Generated by `pipeline/fetch_terrain_window.py`.

| File | Content |
|---|---|
| `dem.f32` | Elevation, little-endian float32, row-major, north row first, NaN = no data. |
| `dem.json` | Grid size, cell size (m), value range, window centre, source product, retrieval time, stated vertical/horizontal control, `synthetic` flag. |
| `route.json` | Curiosity waypoints inside the window, with sol, position, and window-local metres (x east, y south of the NW corner). |
| `qa.json` | Sanity check: DEM elevation minus rover-reported elevation at waypoints (informational; vertical references may differ). |

Regenerate with `python pipeline/fetch_terrain_window.py`. Source and licensing: [docs/DATA.md](../../docs/DATA.md).
